# caseyeickhoff.com

Personal site for Casey Eickhoff, built with [Next.js](https://nextjs.org) 15 (App Router), React 19, and TypeScript.

UI components come from [Spectrum Web Components](https://spectrum-web-components.adobe.com/) gen2 (`@adobe/spectrum-wc`), registered client-side in `src/swc/registry.tsx`. Brand token overrides live in `src/styles/brand/brand.css`.

## Scripts

```bash
npm install
npm run dev    # start the dev server at http://localhost:3000
npm run build  # production build
npm run lint   # ESLint
```
